# totalwar_deckbuilder
Wizcards (tentative title)

Prototype game built with Godot that is a deckbuilding real-time-strategy (RTS) battle game.


# Current state
Still very much in the prototype stage, but getting a bit further along. 

Added some actual UI assets, as well as card/hand management and deck selection (though the decks all use the same default one, for now).  Still only a single prototype battle to try out, but it gives a rough feel for the game.

For debugging, if enabled in the inspector, can place more enemy units with right mouse click.
