# totalwar_deckbuilder
Prototype game built with Godot that is a mix of "total war" style RTS/turn-based(maybe) strategy and deckbuilding.
(need a real title eventually)


# Current state
Still very intro-project level.  Some basic unit logic, where friendly units find and navigate towards enemy units, and attack them.  Can place more units with mouse click.


# Assets
Initial set of graphical assets used are "Minifantasy" from Kirhsna Palacio.  Might end up buying the bundle/license and using these as more than temporary assets.  https://krishna-palacio.itch.io
